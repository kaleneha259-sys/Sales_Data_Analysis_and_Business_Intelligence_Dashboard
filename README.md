# Sales_Data_Analysis_and_Business_Intelligence_Dashboard
End-to-End Sales Analytics Using SQL, Python & Power BI


📌 Project Overview

This project focuses on analyzing sales data to understand sales performance, profit trends, regional sales distribution, and product-wise sales performance.

The project integrates SQL Server, Python, and Power BI to clean, process, analyze, and visualize sales data through an interactive dashboard.

🛠️ Technologies Used

- SQL Server (SSMS): Data storage, SQL queries, and data management.
- Python: Data processing and analysis.
- Pandas: Data manipulation and cleaning.
- SQLAlchemy: Connecting Python with SQL Server.
- PyODBC: Database connectivity.
- Power BI: Interactive dashboard and data visualization.

📂 Project Workflow

1. Imported and stored sales data into SQL Server.
2. Performed data extraction using SQL queries.
3. Connected Python with SQL Server using SQLAlchemy and PyODBC.
4. Used Pandas for data processing and analysis.
5. Connected the processed sales data to Power BI.
6. Created an interactive dashboard to analyze sales and profit performance.

📈 Power BI Dashboard

The dashboard includes the following visualizations:

KPI Cards

- Total Profit
- Profit Percentage
- Total Sales

Charts and Visualizations

- Monthly Sales Analysis
- Region-wise Sales Analysis
- Product-wise Sales Analysis

🎯 Key Objectives

- Analyze overall sales and profit performance.
- Identify monthly sales trends.
- Compare sales across different regions.
- Understand product-wise sales performance.
- Present business insights through an interactive dashboard.
